# Instrucciones para Claude

Antes de analizar o modificar este repositorio, lee y cumple completamente [AGENTS.md](./AGENTS.md).

AGENTS.md es la fuente autoritativa para:

- Alcance y límites.
- Arquitectura aprobada.
- Protección de references/.
- Dependencias.
- Acceso a bases.
- Seguridad, pruebas y documentación.
- Restricciones de Git.

No instales dependencias, no modifiques referencias, no escribas en bases de datos y no tomes decisiones de arquitectura sin autorización explícita.

Todos los cambios deben quedar sin commit. Está prohibido crear ramas, commits o tags, y ejecutar git push.

Si estas instrucciones parecen contradecir AGENTS.md, detén la acción afectada y solicita aclaración.
